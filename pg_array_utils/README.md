# **pg_array_utils**

Расширение реализует набор функций на языке С для преобразования массивов PostgreSQL и манипуляций над ними. 


## Описание задач

Далее описаны задачи, решаемые каждой функцией расширения:
- `array_flatten` – преобразование многомерного массива в одномерный с сохранением порядка элементов;
- `array_chunk` - разбиение одномерного массива на двумерный массив чанков заданного размера с дополнением NULL;
- `array_zip` – объединение нескольких массивов в массив JSON-объектов, где каждый объект содержит значения из соответствующих позиций входных массивов;
- `array_compact` – удаление «пустых» элементов (NULL, нулей, пустых строк) в соответствии с выбранным режимом;
- `array_pad` – дополнение массива до указанной длины заданным значением или массивом;
- `array_slice` – извлечение среза массива по первому измерению с заданным шагом;
- `array_repeat` – создание массива путём повторения заданного элемента или массива указанное число раз.


## Дизайн расширения [^1]

### Общие архитектурные решения:
- Все SQL-функции объявлены как **IMMUTABLE STRICT**, что гарантирует отсутствие NULL-аргументов в C-коде и позволяет использовать функции в индексах и оптимизациях;
- Для работы с массивами применяются стандартные функции PostgreSQL: `deconstruct_array` для разбора массива на элементы и NULL-карту, `construct_array` и `construct_md_array` для сборки результата;
- Большинство функций [^2] поддерживают работу с многомерными массивами с учётом порядка хранения PostgreSQL (row-major);
- Размеры и индексы передаются как **int32**; для больших результатов проверяется превышение `MaxAllocSize`[^3];
- Поведение нижних границ (`lbs`) и обработка NULL-элементов в массивах различаются по функциям и описаны в разделах ниже.
### Алгоритмы и особенности:
#### 1. **array_flatten**
Для многомерного непустого массива используется `deconstruct_array`, затем `construct_array` для сборки одномерного массива с `lbs = 1`. Для одномерного или пустого массива возвращается исходный массив без изменений.
#### 2. **array_chunk**
Входной массив должен быть непустым и одномерным. Вычисляется количество чанков `chunks_cnt = (n + size - 1) / size`, общий размер `new_size = chunks_cnt * size`, где `size` - введенный размер одного чанка. Массивы элементов и NULL-карта расширяются, хвост заполняется NULL, результат собирается через `construct_md_array` с размерностями `{chunks_cnt, size}` и `lbs = {1,1}`.
#### 3. **array_zip**
Для каждого входного массива один раз вычисляется out-функция типа его элементов через `getTypeOutputInfo` и создаётся `ArrayIterator` с глубиной среза `ndim - 1`; определяется `dims[0]` (длина первого измерения) и признак пустоты. Для `i = [0; max_len - 1]` строится JSON-объект с полями `"f1" , "f2" , …`, где i-е поле содержит элемент / подмассив i-го входного массива:
- Для 1D-массивов `array_iterate` возвращает сам элемент, сериализуемый в JSON через `pgau_datum_to_json_cstring` с заранее вычисленной out-функцией;
- Для N-мерных массивов `array_iterate` возвращает готовый подмассив размерности `ndim - 1`, который сериализуется через `pgau_ArrayType_to_StringInfo`.
Каждая JSON-строка преобразуется в `jsonb` через `jsonb_in`; результат собирается `construct_md_array` в массив `jsonb[]` с `lbs = {1}`.
#### 4. **array_compact**
Сначала проверяется существование режима и соответствие режима типу элементов; для пустого массива выполняется ранний возврат аргумента. Непустой массив обходится через `ArrayIterator`:
- `'null'` — пропускаются NULL-элементы;
- `'falsy'` — в зависимости от типа элемента: для `bool` пропускаются NULL и `false`; для числовых/текстовых типов — NULL и «ложные» значения (нули/пустые строки) через `pgau_numeric_is_zero`/`pgau_text_is_empty`; для остальных типов — только NULL (как в режиме `'null'`);
- `'zero'`/`'empty'` — отсеиваются нули/пустые строки соответствующей функцией сравнения; NULL-элементы сохраняются в результирующем массиве.
Для `'null'` и `'falsy'` используется `construct_array` (NULL в результат не попадают), для `'zero'` и `'empty'` — `construct_md_array` с NULL-картой.
**Важно:** названия режимов чувствительны к регистрам! 
#### 5. **array_pad** [^4]
Работа функции различается в зависимости от входного значения. Существует 2 случая:
- Добавляемое значение - скаляр: исходный массив (0D/1D) разбирается, элементы и NULL-карта копируются в нужную позицию, новая память заполняется значением.
- Добавляемое значение - массив: проверяется согласованность размерностей и lower bounds, затем блоки элементов и NULL-карт копируются в нужном порядке. Результат – массив размерности `(N+1)`, где `N` - размерность добавляемого значения.
Результат собирается через `construct_md_array`.
#### 6. **array_slice**
Входной массив должен быть непустым. Индексы start и end нормализуются (1-based, отрицательные индексы означают срез массива с конца). Вычисляется `element_size`, равный произведению `dims[1..]`, затем копируются блоки элементов и NULL-карты с шагом `step * element_size`. Результат собирается через `construct_md_array` с `res_lbs[0] = 1`.
#### 7. array_repeat [^4]
Работа функции различается в зависимости от входного значения. Существует 2 случая:
- Для скалярного значения: создаётся массив длины `count`, заполненный заданным значением, через `construct_array`.
- Для массива: входной массив разбирается, блоки элементов и NULL-карты копируются `count` раз, результат собирается через `construct_md_array` с размерностью `(N+1)`, где `N` - размерность входного массива.

|array_compact(anyarray, text)|anyarray, mode text|anyarray|Удаление «пустых» элементов одномерного массива. `mode` определяет режим работы: `'null'` — удалить NULL, `'zero'` — числовые нули (0), `'empty'` — пустые строки/bytea и т.п. (""), `'falsy'` — удалить NULL, false, 0, ""|

## Примеры использования

##### **array_flatten**
```SQL
-- Преобразование многомерного массива в одномерный

SELECT array_flatten(ARRAY[[['Я','помню'],['чудное','мгновенье:']],[['Передо','мной'],['явилась','ты...']]]);
-- Результат: {Я,помню,чудное,мгновенье:,Передо,мной,явилась,ты...}
```
##### **array_chunk**
```SQL
-- Преобразование одномерного массива в многомерный

SELECT array_chunk(ARRAY[1,2,3,4,5], 2);
-- Результат: {{1,2},{3,4},{5,NULL}}
```
##### **array_zip**
```SQL
-- Слияние нескольких массивов в jsonb[]

SELECT unnest(array_zip(ARRAY[[[1,2],[3,4]],[[5,6],[7,8]]], ARRAY['a','b']));
-- Результат: {"f1": [[1, 2], [3, 4]], "f2": "a"}, {"f1": [[5, 6], [7, 8]], "f2": "b"}
```
##### **array_compact**
```SQL
-- Удаление NULL элементов массива (режим 'null' / по умолчанию)

SELECT array_compact(ARRAY['a',NULL,'b'], 'null');
-- Результат: {a,b}


-- Удаление числовых нулей (режим 'zero')

SELECT array_compact(ARRAY[0.0, 1.5, 0, 2.5]::numeric[], 'zero');
-- Результат: {1.5,2.5}

SELECT array_compact(ARRAY[0,NULL,2], 'zero');
-- Результат: {NULL,2}


-- Удаление пустых строк (режим 'empty')

SELECT array_compact(ARRAY['a','','b',''], 'empty');
-- Результат: {a,b}

SELECT array_compact(ARRAY['x','','y',NULL]::varchar[], 'empty');
-- Результат: {x,y,NULL}


-- Режим 'falsy'

SELECT array_compact(ARRAY[true,false,NULL,true], 'falsy');
-- Результат: {t,t} (удалены NULL и false)

SELECT array_compact(ARRAY[0,1,NULL,2], 'falsy');
-- Результат: {1,2} (удалены NULL и 0)

SELECT array_compact(ARRAY['a','',NULL,'b'], 'falsy');
-- Результат: {a,b} (удалены NULL и '')

SELECT array_compact(ARRAY['2024-01-01'::date, '2024-01-02'::date, NULL], 'falsy');
-- Результат: {01-01-2024,01-02-2024} (удалены NULL)
```
##### **array_pad**
```SQL
-- Дополнение массива до указанной длины введенным значением

SELECT array_pad(ARRAY[1,2], 4, 0);
-- Результат: {1,2,0,0}

SELECT array_pad(ARRAY[1,2], -4, 0);
-- Результат: {0,0,1,2}

SELECT array_pad(ARRAY[[1,2],[3,4]], 3, ARRAY[0,0]);
-- Результат: {{1,2},{3,4},{0,0}}
```
##### **array_slice**
```SQL
-- Нахождение среза массива по первому измерению с шагом

SELECT array_slice(ARRAY[1,2,3,4,5], 1, 5, 2);
-- Ожидается: {1,3,5} (шаг 2)

SELECT array_slice(ARRAY['а','б','в','где','ёж'], -2, -1);
-- Ожидается: {где,ёж} (отрицательные индексы, с конца)

SELECT array_slice(ARRAY[[1,2],[3,4],[5,6]], 1, 2);
-- Ожидается: {{1,2},{3,4}} (срез по первому измерению)
```
##### **array_repeat**
```SQL
-- Создание одномерного массива из заданного элемента / массива, повторённого заданное число раз

SELECT array_repeat('Around the world'::text, 2);
-- Ожидается: {"Around the world","Around the world"}

SELECT array_repeat(ARRAY[[1,2],[3,4]], 2);
-- Ожидается: {{{1,2},{3,4}},{{1,2},{3,4}}}
```

## Инструкция по установке

1. Сборка расширения:
```bash
make USE_PGXS=1
```
*Альтернатива: добавление директории расширения в директорию contrib/ в исходных файлах PostgreSQL и сборка вместе с СУБД.*
2. Установка:
```bash
make USE_PGXS=1 install
```
3. *(Дополнительно)* Запуск тестов расширения:
```bash
make USE_PGXS=1 installcheck
```
4. Создание расширения в базе данных:
```bash
psql -d postgres -c "CREATE EXTENSION pg_array_utils;"
```
